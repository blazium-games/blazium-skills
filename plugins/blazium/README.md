# Blazium

Full bundle: router, MCP, Autowork, engine, live-ops, export/toolchain, content-intelligence, extra-module, and growth-adapter skills. Baseline Blazium 0.8.x (Godot 4.8.x fork, branch `blazium_4.8`).

Install this pack from the [blazium-skills](https://github.com/blazium-games/blazium-skills) marketplace. The skill files are linked into `skills/` by `scripts/sync-plugin-packs.py`.
