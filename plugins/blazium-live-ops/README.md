# Blazium Live Ops

Identity and live services: login, JWT, lobby, Steam/Discord, ENet-WebRTC, dedicated ENet, RCON, Games cloud MCP, crash analytics. Blazium 0.8.x (Godot 4.8.x fork, branch `blazium_4.8`).

Install this pack from the [blazium-skills](https://github.com/blazium-games/blazium-skills) marketplace. The skill files are linked into `skills/` by `scripts/sync-plugin-packs.py`.
