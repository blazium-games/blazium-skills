# Blazium Ship

Export and toolchain: desktop/mobile/web export, GPL retro sidecar, specialty targets, GitHub Actions, CI watch, CLI, Hub, Crash Reporter, ColdStorage. Blazium 0.8.x (Godot 4.8.x fork, branch `blazium_4.8`).

Install this pack from the [blazium-skills](https://github.com/blazium-games/blazium-skills) marketplace. The skill files are linked into `skills/` by `scripts/sync-plugin-packs.py`.
